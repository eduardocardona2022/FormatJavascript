# Archivos de ejemplo

Estos archivos están deliberadamente sin formatear para probar la aplicación:

| Archivo        | Lenguaje         |
| -------------- | ---------------- |
| `example.js`   | JavaScript       |
| `example.jsx`  | JavaScript (JSX) |
| `example.ts`   | TypeScript       |
| `example.tsx`  | TypeScript (TSX) |
| `example.json` | JSON             |
| `example.css`  | CSS              |
| `example.html` | HTML             |
| `example.md`   | Markdown         |

Arrastra cualquiera de ellos a la zona de carga o selecciónalo con el botón. El resultado debería aparecer formateado y con la opción de copiarlo o descargarlo.
